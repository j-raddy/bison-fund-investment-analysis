# Worked examples

Two complete pitches, kept as working folders. You open the HTML in a browser; there is nothing
to present live.

Get the repo, then open the file:

    git clone https://github.com/j-raddy/bison-fund-investment-analysis.git
    open examples/googl-pitch/alphabet-pitch-commentable.html

Clicking an HTML file on github.com shows its source, not the rendered deck, so clone it or use
the download button on the file and open it locally.

Each folder holds the deck as plain HTML to read through and as a commentable HTML for review,
plus the fact sheet the deck was built from. The commentable version adds a toolbar: pick a
section, turn on comment mode, click any block, and Copy feedback exports the notes as markdown.

## Alphabet, October 2026

Built with the current workflow: grounding first, analyst overlay second. The grounding digests
are the interesting part. Four sub-agents collected what the company, the market, and the news
had said, and the deck was built on top of that. Three facts surfaced that the first draft had
missed, including an $84.75B equity raise in June 2026 and a securities class action filed the
day the deck was finished.

Files: `alphabet-pitch.html`, `alphabet-pitch-commentable.html`, `factsheet.md`, `grounding-1-business.md` through
`grounding-4-peers.md`, and `grounding-merged.md`.

Data as of October 9, 2026. Consensus figures rest on aggregator reproduction of sell-side notes;
the deck's source note says to confirm before presenting.

## Uber, October 2026

Built before the grounding phase existed, so it is opinion-led in a way the Alphabet deck is not.
Worth comparing the two: the Uber deck argues a thesis; the Alphabet deck presents the record and
then argues from it. No grounding digests exist for Uber because none were made.

Files: `uber-pitch-deck.html`, `uber-pitch-deck-commentable.html`, `factsheet.md`.

Data as of October 9, 2026.

## A note for students

These are examples of the process, not recommendations about the companies. Both decks carry dated
data and a dated view. If you reuse anything, restate the date and re-check the numbers.

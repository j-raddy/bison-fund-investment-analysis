# Worked examples

Two complete pitches, kept as working folders rather than presentations. Clone or pull the repo
and open the files locally; nothing here needs to be presented live.

Each folder holds the same four things:

- `factsheet.md` - the sourced numbers the deck was built from
- the deck, as plain HTML to present from and as a commentable HTML for review
- for Alphabet, the four grounding digests and their merged file

Open the HTML in a browser. The commentable version adds a toolbar: pick a section, turn on
comment mode, click any block, and the feedback exports as markdown.

## Alphabet, October 2026

Built with the current workflow: grounding first, analyst overlay second. The grounding digests
are the interesting part. Four research lanes collected what the company, the press, and peers
had said, and the deck was built on top of that record. Three facts came out of grounding that
the first draft had missed, including an $84.75B equity raise in June 2026 and a securities class
action filed the day the deck was made.

Data as of October 9, 2026. The consensus figures rest on aggregator reproduction of sell-side
notes, which the deck's source note says to confirm before presenting.

## Uber, October 2026

Built before the grounding phase existed, so it is opinion-led in a way the Alphabet deck is not.
Worth comparing the two: the Uber deck argues a thesis; the Alphabet deck presents the record and
then argues from it. The Uber folder has no grounding digests because none were made.

Data as of October 9, 2026.

## A note for students

These are examples of the process, not recommendations about the companies. Both decks carry
dated data and a dated view. If you reuse anything, restate the date and re-check the numbers.
